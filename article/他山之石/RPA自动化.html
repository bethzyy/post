RPA 自动化

RPA = Robotic Process Automation（机器人流程自动化）

简单说：用软件机器人模拟人工操作，自动完成重复性任务。

工作原理

人工操作：打开Excel → 复制数据 → 打开系统 → 粘贴 → 点击提交
↓
RPA机器人：录屏学习上述操作 → 24小时不间断自动执行

常见应用场景

场景 示例
数据录入 Excel 数据自动填入 ERP 系统
报表生成 定时拉取数据、生成报表、发邮件
发票处理 识别发票 → 提取信息 → 录入财务系统
客服工单 自动分类、分配、回复简单问题
银行对账 多系统数据核对、异常标记

类型 代表产品

RPA vs 其他自动化

对比项 RPA API 集成 AI 自动化
需要编程 ❌ 不需要 ✅ 需要 ✅ 需要
模拟人工 ✅ 是 ❌ 否 部分
适用系统 任何有界面的系统 需要有 API 需要训练数据
稳定性 界面变化会失效 较稳定 取决于模型

优缺点

优点 缺点
无需改现有系统 界面变化容易出错
上手快、见效快 不适合复杂决策
24小时工作 需要维护机器人脚本
投资回报率高 无法处理非标准化流程
一句话总结：RPA = 让软件机器人帮你干那些"复制粘贴、点点点"的重复活儿。
