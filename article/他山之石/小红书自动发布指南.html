📱 小红书自动发布指南

将今日头条文章一键发布到小红书的完整教程

📖概述

本指南介绍如何使用 Claude Desktop 配合小红书 MCP 服务器，将今日头条文章自动发布到小红书平台。通过 MCP (Model Context Protocol) 工具，您可以：

  • 自动化发布：无需手动复制粘贴，一键完成发布
  • 智能适配：自动调整标题长度、内容格式
  • 批量管理：高效处理多篇文章的迁移
  • 安全合规：内置敏感词检测和频率控制

🔧前期准备

1. 安装小红书 MCP

1下载可执行文件
访问 GitHub Releases 下载对应平台的版本：
  • xiaohongshu-mcp-windows-amd64.exe (Windows)
  • xiaohongshu-mcp-darwin-amd64 (macOS Intel)
  • xiaohongshu-mcp-darwin-arm64 (macOS Apple Silicon)
  • xiaohongshu-mcp-linux-amd64 (Linux)
2放置文件
下载后重命名为 xiaohongshu-mcp.exe (Windows) 或 xiaohongshu-mcp (macOS/Linux)，放入目录：
C:\D\CAIE_tool\MyAIProduct\mcp-servers\xiaohongshu\

2. 配置 Cookie

获取 Cookie 详细指南：
运行命令 python manage.py --guide 查看完整教程

简要步骤：

  1. 打开浏览器，登录 小红书网页版
  2. 按 F12 打开开发者工具
  3. 进入 Application → Cookies → https://www.xiaohongshu.com
  4. 复制以下 4 个 Cookie 值：
    • web_session - 长字符串
    • webId - UUID 格式
    • a1 - 长字符串
    • webBuild - 版本号（如 4.55.2）
3编辑配置文件
编辑 config.json，填入 Cookie 值： 
{
  "cookies": {
    "web_session": "你的值",
    "webId": "你的值",
    "a1": "你的值",
    "webBuild": "你的值"
  },
  "publishSettings": {
    "maxDailyPosts": 3,
    "minIntervalMinutes": 120
  }
}
安全提醒：Cookie 有效期约 7 天，请妥善保管 config.json 文件，不要上传到公共仓库。

3. 配置 Claude Desktop

编辑 Claude Desktop 配置文件：

Windows: %APPDATA%\Claude\claude_desktop_config.json

{
  "mcpServers": {
    "xiaohongshu": {
      "command": "C:\\D\\CAIE_tool\\MyAIProduct\\mcp-servers\\xiaohongshu\\xiaohongshu-mcp.exe",
      "args": ["--config", "C:\\D\\CAIE_tool\\MyAIProduct\\mcp-servers\\xiaohongshu\\config.json"]
    }
  }
}

macOS/Linux: ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "xiaohongshu": {
      "command": "/path/to/mcp-servers/xiaohongshu/xiaohongshu-mcp",
      "args": ["--config", "/path/to/mcp-servers/xiaohongshu/config.json"]
    }
  }
}
完成后重启 Claude Desktop 即可使用！

实际操作示例

👤 用户：请帮我将这篇今日头条文章发布到小红书：
[粘贴文章内容或提供URL]

要求：
- 标题：[简短标题，不超过20字]
- 话题：#标签1 #标签2
- 图片：/path/to/image1.jpg, /path/to/image2.jpg

🤖 Claude：我来帮您将文章发布到小红书。首先让我调整格式...

[Claude 自动调用 create_post 工具完成发布]
提示：Claude 会自动调整内容格式以符合小红书的要求，包括标题长度、正文长度等。

✏️内容适配

标题调整（≤ 20字）

  • 保留核心关键词
  • 使用吸引人的表达
  • 适当使用表情符号
  • 示例：
    • 原标题：「深度学习在自然语言处理中的应用研究」(17字)
    • 调整后：「AINLP：深度学习的NLP应用」(15字)

正文调整（≤ 1000字）

  • 提炼核心观点
  • 删除冗余内容
  • 使用分段提升可读性
  • 添加小标题和要点列表

话题标签添加

小红书话题标签格式：#话题名称

常用话题示例：

#干货分享 #学习笔记 #职场经验 #技术分享 #AI工具 #效率提升

图片处理建议

  • 格式：支持 JPG、PNG
  • 大小：建议 < 10MB
  • 数量：最多 9 张
  • 比例：建议 3:4 或 1:1
  • 质量：清晰、高对比度

❓常见问题

Cookie 过期处理

症状：发布失败，提示未登录或认证失败

解决方法：

  1. 检查 Cookie 状态：python manage.py --check
  2. 更新 Cookie：python manage.py --update
  3. 按照提示重新输入 Cookie 值

发布失败排查

错误提示 可能原因 解决方法
认证失败 Cookie 无效或过期 更新 Cookie
标题过长 标题超过 20 字 精简标题
内容过长 正文超过 1000 字 精简内容
图片上传失败 图片格式或大小问题 压缩图片或更换格式
包含敏感词 内容触发审核规则 使用敏感词预检工具

频率限制建议

重要：为避免账号风险，请严格遵守频率限制
  • 每日发布 ≤ 3 篇
  • 发布间隔 > 2 小时
  • 避免同时操作多个账号
  • 如提示操作频繁，请等待 24 小时后重试

💡最佳实践

发布频率控制

建议频率：
每日 1-2 篇，选择用户活跃时段发布（如 9:00-11:00, 18:00-21:00）

内容合规检查

  • 发布前使用敏感词预检
  • 避免硬性营销词汇
  • 确保内容真实可信
  • 遵守社区规范和法律法规

话题标签优化

  • 选择 3-5 个相关话题标签
  • 结合热门话题提升曝光
  • 使用垂直领域精准标签
  • 定期调整标签策略

内容质量提升

  • 标题吸引人但不夸张
  • 配图高质量且相关
  • 内容结构清晰易读
  • 互动回应评论和私信
