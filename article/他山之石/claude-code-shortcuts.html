快捷键使用频率排名

以下快捷键按日常使用频率从高到低排序，建议优先掌握排名靠前的快捷键。

排名 快捷键 功能 频率
1 Ctrl+C 取消当前输入或停止生成
Claude 回复太长需要中断、生成方向错误、输入一半想取消		 极高
2 Ctrl+L 清除终端屏幕（保留对话历史）
屏幕太乱需要清理、想清空终端但不想丢失对话历史		 极高
3 ↑ / ↓ 导航命令历史
重复执行之前的命令、查看之前输入的提示词		 极高
4 Ctrl+R 反向搜索命令历史
想找之前执行的某个命令但记不清具体内容		 高
5 \ + Enter 多行输入（换行）
输入复杂的提示词需要换行、写多行代码示例		 高
6 Shift+Tab 切换权限模式
在自动接受模式、计划模式和普通模式之间切换		 中高
7 Ctrl+O 切换详细输出模式
调试时想看 Claude 内部思考过程		 中高
8 Tab 切换扩展思考模式
复杂任务需要深度思考		 中
9 Esc+Esc 回退代码/对话
Claude 改错了代码需要撤销、想回到之前的状态		 中
10 Ctrl+D 退出 Claude Code
结束工作、关闭 Claude Code 会话		 低
11 Ctrl+V 粘贴图像（Windows: Alt+V）
粘贴截图进行 UI 分析、分享错误截图让 Claude 诊断		 中
12 Alt+P 不清空输入框切换模型
保留当前提示词切换到不同模型		 低

按功能分类

常规控制

  • Ctrl+C - 取消当前输入或生成
  • Ctrl+D - 退出 Claude Code
  • Ctrl+L - 清屏（保留历史）

历史与搜索

  • ↑ / ↓ - 导航命令历史
  • Ctrl+R - 反向搜索历史

模式切换

  • Shift+Tab - 切换权限模式
  • Tab - 切换扩展思考
  • Ctrl+O - 切换详细输出

输入控制

  • \ + Enter - 多行输入（通用）
  • Option+Enter - 多行输入（macOS）
  • Shift+Enter - 多行输入（需配置）

撤销与回退

  • Esc+Esc - 回退代码/对话
  • Ctrl+_ - 撤销操作

文本编辑快捷键

快捷键 功能
Ctrl+A 跳到行首
Ctrl+E 跳到行尾
Ctrl+W 删除单词
Ctrl+U 删除整行
Ctrl+K 删除到行尾

快速命令

在输入开始时输入这些字符可以触发特殊功能：

命令 功能
/ 斜杠命令，如 /help、/clear、/compact 等
! Bash 模式，直接运行 Shell 命令
@ 文件路径引用，触发自动补全
# 内存快捷方式，添加到 CLAUDE.md
& 后台运行

重要提示

macOS 用户注意

macOS 用户需要在终端中将 Option 键配置为 Meta 键，才能使用 Alt+P、Alt+T 等快捷键。

  • iTerm2：Preferences → Profiles → Keys → Left Option Key → Esc+
  • Terminal.app：Preferences → Profiles → Keyboard → Use Option as Meta key
自定义快捷键：运行 /keybindings 命令可以创建或编辑配置文件。修改配置后会自动热重载，无需重启。

学习建议

  1. 第一阶段（必掌握）：Ctrl+C、Ctrl+L、↑/↓、Ctrl+R、\ + Enter
  2. 第二阶段（常用）：Shift+Tab、Ctrl+O、Tab、Esc+Esc、Ctrl+V
  3. 第三阶段（进阶）：Alt+P/T、Ctrl+S、Ctrl+_、文本编辑快捷键
  4. 第四阶段（专家）：自定义快捷键、Vim 编辑模式

常用斜杠命令

  • /help - 显示帮助信息
  • /clear - 清除对话历史
  • /init - 初始化项目配置
  • /model - 切换 AI 模型
  • /config - 打开配置面板
  • /cost - 查看 Token 消耗
