🎯 一、先搞懂三个核心概念

很多新手容易混淆这三个概念，先明确一下：

  • 快捷键：键盘组合键（如 Ctrl+C），按下立即生效，不需要回车
  • 斜杠命令：以 / 开头的文本命令（如 /help），输入后需要按回车执行
  • 特殊前缀：!/@/#/& 等符号开头的快捷输入方式，触发特定功能
💡 记忆技巧：快捷键像"一键触发"，斜杠命令像"程序指令"，特殊前缀像"快捷方式"

⌨️ 三、键盘快捷键完整清单

1. 常规控制

  • Ctrl+C - 取消当前输入或生成
  • Ctrl+D - 退出Claude Code
  • Ctrl+L - 清屏（保留历史）
  • ? - 查看可用快捷键

2. 历史与搜索

  • ↑ / ↓ - 导航命令历史
  • Ctrl+R - 反向搜索历史

3. 模式切换

  • Shift+Tab - 切换权限模式
  • Alt+M - 切换权限模式（备选）
  • Tab - 切换扩展思考模式
  • Ctrl+O - 切换详细输出模式
  • Esc+Esc - 回退代码/对话

4. 多行输入方法对比

快捷键 适用环境 说明
\ + Enter 所有终端 最通用的方式，推荐
Option+Enter macOS默认 macOS上的默认设置
Shift+Enter 需配置 运行/terminal-setup后可用

💬 四、斜杠命令完整清单

斜杠命令需要输入完整命令后按回车执行，不同于快捷键。以下是常用命令分类：

1. 基础命令（高频使用）

  • /help - 显示帮助信息
  • /clear - 清除对话历史
  • /exit - 退出Claude Code
  • /compact - 压缩对话历史

2. 项目管理

  • /init - 初始化项目配置
  • /add-dir - 添加工作目录
  • /commit - 创建Git提交

3. 配置管理

  • /config - 打开配置面板
  • /model - 切换AI模型
  • /keybindings - 打开快捷键配置
  • /terminal-setup - 配置终端快捷键

⚡ 五、特殊前缀快捷输入

在输入开始时输入这些字符可以触发特殊功能：

前缀 功能 示例
! Bash模式，直接运行Shell命令 ls -la
@ 文件引用，触发路径自动补全 @src/main.ts
# 内存快捷方式，添加到CLAUDE.md #always use npm
& 后台运行命令 &npm run dev
/ 斜杠命令（见上面章节） /help

⚠️ 六、重要注意事项

macOS用户注意

macOS用户需要在终端中将Option键配置为Meta键，才能使用Alt+B、Alt+F等文本编辑快捷键。

Shift+Enter配置

如果你使用VS Code Terminal、Alacritty、Zed或Warp，需要先运行/terminal-setup命令安装键位绑定。

自定义快捷键：运行/keybindings命令可以创建或编辑配置文件。修改配置后会自动热重载，无需重启。
查看可用快捷键：在Claude Code中按?可以查看当前环境中可用的所有快捷键。快捷键可能因平台和终端而异。

💡 八、实战技巧分享

1. 提升效率的黄金组合

  • Ctrl+R + 关键词 - 快速找到历史命令
  • @文件路径 + Tab - 自动补全文件路径
  • /commit - 自动生成规范的Git提交信息

2. 新手常见误区

  • 误区：以为斜杠命令需要快捷键触发
    真相：直接输入命令+回车即可
  • 误区：不知道多行输入怎么换行
    真相：使用\+Enter（所有终端通用）
  • 误区：对话太长不知道怎么办
    真相：使用/compact压缩上下文

3. 高级技巧

  • 使用#always use npm可以让Claude记住你的偏好
  • 使用&前缀可以后台运行开发服务器
  • 使用!前缀快速执行Shell命令而不退出对话
