## 生成步骤

### 第一步：读取原始节气文档

1. 读取 `{节气名}.html` 文件
2. 提取4组颜色的名称和色彩意象描述
3. 提取结尾的整体意境描述

### 第二步：创建配图生成脚本

创建 `generate_{节气名拼音}_images.py`，包含：

#### API配置
```python
from config import get_volcano_client, get_antigravity_client

volcano_client = get_volcano_client()  # 火山引擎 Seedream
antigravity_client = get_antigravity_client()  # Antigravity
```

#### 图片尺寸设置
- **横版（推荐）**: `size="1920x1080"` (16:9)
- **正方形**: `size="2048x2048"` (1:1)

**注意**: Seedream 4.5/4.0 使用 `"1920x1080"` 格式，不是 `"16:9"` 或 `"1:1"`

#### 降级策略
1. Seedream 4.5 → Seedream 4.0 → Antigravity → Pollinations

### 第三步：运行配图生成脚本

```bash
cd C:\D\CAIE_tool\MyAIProduct\postrticle\二十四节气色彩
python generate_{节气名拼音}_images.py
```

预计生成6-7张图片，耗时约3-5分钟。

### 第四步：创建配图版HTML文档

创建 `{节气名}_配图版.html`，**严格按照以下格式**：

#### HTML文档格式规范（重要！）

##### 1. 开头引用块格式

四组颜色之间**不要有空行**，每组颜色单独一行：

```html
<blockquote>
昌荣、紫薄汗、茈藐、紫紶<br>
苍葭、庭芜绿、翠微、翠虬<br>
碧落、挼蓝、青雀头黛、螺子黛<br>
露褐、檀褐、緅絺、目童子
</blockquote>
```

**错误示例**（不要这样写）：
```html
<blockquote>
昌荣、紫薄汗、茈藐、紫紶<br><br>
苍葭、庭芜绿、翠微、翠虬<br><br>
...
</blockquote>
```

##### 2. 色彩意象段落格式

颜色描述**必须分行列举**，使用列表格式：

```html
<p>色彩意象：浮萍初生，水面泛紫。</p>

<ul class="color-list">
<li>- "昌荣"是草木昌盛的荣光之色</li>
<li>- "紫薄汗"是薄汗浸出的淡淡紫红</li>
<li>- "茈藐"是紫草的深紫色</li>
<li>- "紫紶"是紫色丝带的华贵</li>
</ul>

<p>水面上的浮萍，从嫩绿到深紫，是春天末尾水色变幻的写照。</p>
```

**CSS样式**（添加到`<style>`中）：
```css
.color-list {
    margin: 15px 0;
    padding-left: 0;
}
.color-list li {
    list-style: none;
    margin: 8px 0;
}
```

##### 3. 图片占位方案

如果图片生成API暂时不可用，可以使用CSS渐变色作为占位图：

```html
<div class="image-placeholder" style="background: linear-gradient(135deg, #e1bee7 0%, #ce93d8 30%, #ab47bc 70%, #7b1fa2 100%);">
    图片主题描述<br>
    <small>{颜色名称}</small>
</div>
```

占位图渐变色应与该组颜色主题对应：
- 紫色系：`#e1bee7 → #ce93d8 → #ab47bc → #7b1fa2`
- 绿色系：`#c8e6c9 → #81c784 → #4caf50 → #2e7d32`
- 青蓝系：`#b3e5fc → #4fc3f7 → #0288d1 → #01579b`
- 褐色系：`#d7ccc8 → #a1887f → #8d6e63 → #5d4037`

### 第五步：更新文档索引

在 `二十四节气配图文档索引.html` 中更新节气状态：

```html
<!-- 将 -->
<a href="{节气名}_配图版.html" class="solar-term"><span class="name">{节气名}</span><span class="status">○</span></a>

<!-- 改为 -->
<a href="{节气名}_配图版.html" class="solar-term available"><span class="name">{节气名}</span><span class="status">✓</span></a>
```

## 常见问题

### Q: 图片暂时无法生成怎么办？
A: 使用CSS渐变色占位图，每个占位图使用与该组颜色主题对应的渐变色，等API恢复后再替换为真实图片
